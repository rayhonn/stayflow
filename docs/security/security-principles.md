# Security Principles

- Deny by default.
- Authentication and authorization are separate.
- Property/tenant scope is enforced server-side.
- UI hiding is not security.
- Sensitive guest identity access is separately permissioned and auditable.
- No raw card storage.
- Secrets are never committed.
- Privileged support access is time-limited and audited.
- High-impact actions use maker-checker approval where configured.
